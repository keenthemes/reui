## v2.5.2 - 1 September, 2026.

**New: Data Grid Editing API and Localization.**

- `DataGridCellSelection` gains `apiRef` with `focusCell(rowId, columnId, { edit })`, landing cell focus, DOM focus and `aria-activedescendant` together on rows still mounting - [Docs](/docs/components/base/data-grid#datagridcellselection).
- Fill handle looks via `tableLayout.cellFillHandleVariant`: the default solid dot, an Excel-style square, or a Sheets-style hollow ring on the selection corner - [Docs](/docs/components/base/data-grid#datagrid).
- `tableClassNames.rowPinned`, `rowCreate` and `cellFillHandle` override the pinned-row chrome, the add-row affordance and the fill handle - [Docs](/docs/components/base/data-grid#datagridtableclassnames).
- New `getDataGridVisibleSelectedCellCount` helper keeps a selection count consistent with the painted range - [Docs](/docs/components/base/data-grid#datagridcellselection).
- The virtual layout renders `onRowCreate` and `appendRow`, matching the standard body - [Docs](/docs/components/base/data-grid#datagridtablevirtual).
- `onCellSelectionChange` delivers a resolved selection snapshot: the focused cell, every bound, the active bound and the visible cell count - [Docs](/docs/components/base/data-grid#datagrid).
- Per-row editability: `cellEdit.editable` accepts a function of the row, locking rows across paste, fill, clear and the editors - [Docs](/docs/components/base/data-grid#datagridcellselection).
- New `invertDataGridCellsChange` helper derives the undo batch from any `onCellsChange` payload - [Docs](/docs/components/base/data-grid#datagridcellselection).
- The imperative api gains `clearSelection` and `scrollToCell`, and the add-row label is localizable via `rowCreateLabel` - [Docs](/docs/components/base/data-grid#datagridcellselection).
- Copy and cut now work from the keyboard on every platform: Cmd/Ctrl+C and X write through the async clipboard API, since browsers never fire a native copy for a focused grid - [Docs](/docs/components/base/data-grid#datagridcellselection).
- Opt-in single-click editing via `tableLayout.cellEditMode: "click"`; double-click stays the default - [Docs](/docs/components/base/data-grid#datagrid).
- The selection edge beside a pinned column is painted once, inside the cell, so browser zoom and fractional widths can no longer double it into a 2px blur - [Preview](/components/data-grid).
- In-cell controls follow the two-step gesture: the first click on an unfocused cell only focuses it, the second activates the select, date or combobox, matching editor cells - [Docs](/docs/components/base/data-grid#datagridcellselection).
- Pinned columns now show the row hover and selected tints, premixed over their opaque background - [Preview](/components/data-grid).
- Selected rows no longer draw the 2px start bar; the checkbox and row tint carry the state - [Preview](/components/data-grid).
- `i18n` on DataGrid replaces every built-in string in one place, menu items and aria labels included, with function labels for interpolated copy - [Docs](/docs/components/base/data-grid#internationalization).
- Opt-in column virtualization for `DataGridTableVirtual`: only the horizontal window of center columns renders, pinned columns stay mounted, with controlled `scrollToColumnIndex` - [Docs](/docs/components/base/data-grid#datagridtablevirtual).
- `onCellsCopy` reports every clipboard write with the copied grid and a cut flag, for toast confirmations - [Docs](/docs/components/base/data-grid#datagrid).
- `tableLayout.cellEditEnterAdvance` restores the Sheets move-down; an Enter commit now keeps focus on the edited cell by default - [Docs](/docs/components/base/data-grid#datagrid).
- `data-cell-control` marks a custom widget whose active surface is wider than its buttons, so a press anywhere on it follows the two-step gesture - [Docs](/docs/components/base/data-grid#datagridcellselection).
- 3 new examples: a localized grid with an EN / DE / JA switch, a 36-column virtualized matrix, and a server side paginated grid with a debounced search and a status filter, taking the Data Grid to 34 examples per base - [Preview](/components/data-grid).
- Server side pagination is documented end to end: pass the server total twice, as `rowCount` on `useTable` for the page buttons and as `recordCount` on `DataGrid` for the info text - [Docs](/docs/components/base/data-grid#server-side-pagination).

**Fixes & Improvements:**

- `DataGridCellSelection`: Sheets-style chrome, with a lighter tint, a solid perimeter that tracks the drag, an unfilled anchor cell and a dashed fill marquee - [Preview](/components/data-grid).
- `DataGridCellSelection`: the perimeter's top line is clamped inside the first row, so a sticky header cannot paint over it - [Preview](/components/data-grid).
- `DataGridCellSelection`: the perimeter survives the first and last column and the last row, and the fill handle stays inside the grid - [Preview](/components/data-grid).
- `DataGridCellSelection`: the built-in editor sits exactly on the cell, so opening it no longer grows the row by 2px, and it is named after its column - [Preview](/components/data-grid).
- `DataGridCellSelection`: copy, cut, clear, paste and fill act only on visible rows, so a page-boundary range cannot write hidden ones - [Docs](/docs/components/base/data-grid#datagridcellselection).
- `DataGridCellSelection`: a fill across columns runs the target's `parse` and reports rejections, like a paste - [Docs](/docs/components/base/data-grid#datagridcellselection).
- `DataGridCellSelection`: Shift and arrows still extend a range after a modifier click on a control cell - [Docs](/docs/components/base/data-grid#datagridcellselection).
- `DataGridCellSelection`: Escape on an in-cell control returns focus to the grid, and AltGr chords type instead of selecting all - [Docs](/docs/components/base/data-grid#datagridcellselection).
- `DataGridTable`: `columnsResizeMode: "onChange"` writes widths to the table element, so a drag costs no React render per move - [Docs](/docs/components/base/data-grid#datagrid).
- `DataGridTable`: pinned header cells stay put under a sticky header, so the corner no longer scrolls away - [Preview](/components/data-grid).
- `DataGridTable`: the resize handle is its own `data-slot` span, so an end-aligned header cannot swallow the menu click - [Docs](/docs/components/base/data-grid#datagridtable).
- `DataGridTable`: `aria-rowcount` counts pinned extras and `aria-multiselectable` follows the selection mode - [Preview](/components/data-grid).
- `DataGridTableVirtual`: rows and the header row are memoized, so a scroll frame renders only what enters the window - [Docs](/docs/components/base/data-grid#datagridtablevirtual).
- `DataGrid`: `meta.autoSize` columns reflow with the container down to `minSize`, and leave a dragged width alone - [Docs](/docs/components/base/data-grid#datagrid).
- `DataGrid`: `onRowCreate` hands focus to the grid when a draft replaces it, and its click survives a multi-cell selection - [Docs](/docs/components/base/data-grid#datagrid).
- `DataGridPagination`: the page-size select no longer clips 3-digit sizes, and page buttons carry accessible names - [Docs](/docs/components/base/data-grid#datagridpagination).
- `DataGridTableRowPin`: bottom-pinned rows cast their boundary shadow upward - [Docs](/docs/components/base/data-grid#datagridtablerowpin).
- `Combobox`: chips in the spreadsheet editing example are outline badges with an avatar and a remove button - [Preview](/components/data-grid).

## v2.5.0 - 26 August, 2026.

**New: Data Grid Spreadsheet Editing.**

- Cell range selection with drag, Shift and Ctrl ranges and full keyboard navigation, opt-in via `tableLayout.cellSelection` - [Docs](/docs/components/base/data-grid#datagridcellselection).
- Clipboard copy, cut and paste with Excel and Google Sheets TSV round-trip, including bulk paste across a range - [Docs](/docs/components/base/data-grid#datagridcellselection).
- Fill handle repeats the selection down or right, with a live drag preview - [Preview](/components/data-grid).
- One batched `onCellsChange` write contract plus per-column `meta.cellEdit` parse, format and clear rules - [Docs](/docs/components/base/data-grid#datagridcellselection).
- Notion-style editing flow: built-in text and textarea cell editors via `cellEdit.control`, opened by Enter, F2, typing or double-click - [Docs](/docs/components/base/data-grid#datagridcellselection).
- Consumer editors keep the same keystrokes through `onCellEditRequest` for custom controls like selects - [Docs](/docs/components/base/data-grid#datagridcellselection).
- Full spreadsheet keyboard map: Ctrl+Arrows, Home/End, PageUp/PageDown jumps with Shift extension - [Docs](/docs/components/base/data-grid#datagridcellselection).
- ARIA grid semantics: role, row and column indexes, aria-sort, aria-selected and aria-activedescendant tracking for screen readers - [Docs](/docs/components/base/data-grid#datagridcellselection).
- Optional CRUD affordances: an `onRowCreate` add-row, `getRowStatus` row tints and `getCellStatus` corner marks - [Docs](/docs/components/base/data-grid#datagridcellselection).
- One column can absorb the resize filler strip via `meta.fillWidth`, keeping the grid full-width - [Docs](/docs/components/base/data-grid#datagridcellselection).
- New `DataGridSelectionBar` shell for bulk edits over row selection - [Docs](/docs/components/base/data-grid#datagridselectionbar).
- Works alongside sorting, pagination, resizable and pinned columns; existing grids render byte-identically with the flag off - [Docs](/docs/components/base/data-grid#datagridcellselection).

**New Components:**

- New spreadsheet editing example: inline editors, a team member combobox, a date picker, quick add-row and a bulk edit bar, taking the Data Grid to 31 examples per base - [Preview](/components/data-grid).

**Fixes & Improvements:**

- `DataGridTable`: cell borders no longer float against the resize filler strip when `cellBorder` meets `columnsResizable` - [Preview](/components/data-grid).
- `DataGridTable`: resize handles no longer double the header separators when `cellBorder` is on - [Preview](/components/data-grid).
- `DataGridTable`: end-pinned columns resize from their start edge, indicator on the correct side - [Preview](/components/data-grid).
- `DataGridTable`: the viewport no longer draws a browser focus outline during keyboard navigation - [Preview](/components/data-grid).
- `DataGridCellSelection`: the focused cell ring is a quiet 1px border-tone outline, and the editor keeps text exactly in place - [Preview](/components/data-grid).

## v2.3.0 - 19 August, 2026.

**New component - Cascader:**

- A nested multi-level combobox with drill-down navigation, breadcrumbs, search and custom rows. Three modes from one state machine: `drill` (default), `columns` and `tree` - [Docs](/docs/components/base/cascader).
- Selection is opt-in per level. Pressing a branch NAVIGATES rather than selects until `selectable="any"`, so a parent is never chosen by accident on the way to its children - [Docs](/docs/components/base/cascader).
- Async levels come from `getChildren` rather than from mutating `items`, so a lazily loaded tree needs no local copy of the data - [Docs](/docs/components/base/cascader).
- 20 examples across both twins, covering multi-select with a selection cap, indeterminate branches, inline tree expansion, footers and virtualized lists - [Preview](/components/cascader).

**Filters rebuilt:**

- The value is now ONE `FilterQuery` tree rather than an array of chips. Seed it with `createFilterQuery()`, read it with `flattenFilterConditions`, and drive it through `query` / `onQueryChange` or uncontrolled `defaultQuery` - [Docs](/docs/components/base/filters).
- `variant` picks the chrome: `basic` for the chip bar, `advanced` for the builder panel (`advancedMode` `popover` or `inline`). Both edit the same tree - [Docs](/docs/components/base/filters).
- The builder edits values in the row itself for text and number, and reserves popovers for lists and ranges - [Preview](/components/filters).

**Breaking changes:**

- The pre-rewrite Filters props are gone. `filters` / `onChange` and `createFilter()` no longer exist; use `query` / `onQueryChange` and `createFilterQuery()` - [Docs](/docs/components/base/filters).

**Fixes & Improvements:**

- Component docs previews now render inside an iframe and mount only when scrolled into view. A page with dozens of live examples used to mount all of them at once, which was the slowest thing about browsing the component pages - [Preview](/components/data-grid).
- Filters drag and drop keeps the dragged row readable instead of fading it almost to nothing, and the drop indicator lines up with the row it will land beside - [Preview](/components/filters).
- Choosing an attribute in the Filters chip hands off to the condition menu without the field picker flashing behind it, and the value menu now opens aligned to the value segment on the first open - [Preview](/components/filters).

## v2.2.0 - 5 August, 2026.

**Data Grid on TanStack Table v9:**

- The Data Grid now runs on TanStack Table v9. Tables are created with `useTable({ features: dataGridFeatures })`, so there is no more per-table `getCoreRowModel` / `getSortedRowModel` / `getFilteredRowModel` / `getPaginationRowModel` wiring - [Docs](/docs/components/base/data-grid).
- New public surface on the installed primitive: the ready-made `dataGridFeatures` bundle, plus the `DataGridFeatures`, `DataGridTableInstance`, `DataGridColumnMeta` and `DataGridLayoutProps` types - [Docs](/docs/components/base/data-grid).
- Installing the Data Grid no longer widens TanStack's `ColumnMeta` for every other table in your app. The global module augmentation is gone, replaced by a `DataGridColumnMeta` interface wired through the bundle's `columnMeta` slot - [Docs](/docs/components/base/data-grid).
- The React Compiler opt-out is no longer the default. `"use no memo"` came out of 78 registry files; the primitive reads state through TanStack's `Subscribe` instead, and the few examples that still need it each carry a comment saying why - [Preview](/components/data-grid).
- All 30 Data Grid examples, plus the two Filters examples that drive a grid, were updated for v9 in both the Base UI and Radix twins - [Preview](/components/data-grid).

**Breaking changes:**

- The Data Grid now needs `@tanstack/react-table` v9 in your project. The docs ship a copy-paste migration prompt that walks a coding agent through the whole port - [Docs](/docs/components/base/data-grid#prompt-for-tanstack-table-v9-migration).
- Column pinning moved from `left` / `right` to `start` / `end`. That covers `initialState.columnPinning`, `column.pin()` and `getIsPinned()`, and the emitted `data-pinned`, `data-last-col` and `data-outer-pinned-col` attributes. CSS selecting `[data-pinned="left"]` needs updating to `[data-pinned="start"]` - [Docs](/docs/components/base/data-grid).
- `DataGridProps` takes a leading `TFeatures` generic, `useDataGrid` is generic, and the sub-component prop types are feature-parameterized. `VisibilityState` is now `ColumnVisibilityState` - [Docs](/docs/components/base/data-grid).

**Fixes & Improvements:**

- Row drag and drop holds the other rows still instead of sliding them apart, and marks the destination with an indicator bar. New `dropIndicator` prop, on by default - [Preview](/components/data-grid).
- The row drag clone is portalled to the document body and measured to the row it was lifted from, so it stays under the pointer inside containers that create a fixed-position containing block - [Preview](/components/data-grid).
- Columns marked `meta.autoSize` stay resizable. A width you drag by hand is no longer overwritten by the next viewport measurement - [Preview](/components/data-grid).
- Column resizing draws a full-height indicator at the pointer, exposed as `data-slot="data-grid-table-resize-indicator"` for styling - [Preview](/components/data-grid).
- The Icon Tile corner radius now scales with the tile instead of using one flat value, so the softer styles no longer render their `xs` and `sm` sizes as full circles - [Preview](/components/icon-tile).
