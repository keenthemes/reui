## v2.8.1 - 15 October, 2026.

Shadcn Trace arrives with 22 examples, File Type learns 72 more formats, and the Data Grid, Event Calendar, Gantt and Date Selector now work in apps that run React Compiler. This entry covers every free change since v2.8.0.

**New: Shadcn Trace.**

- New Trace category for shadcn's step list: reasoning, tool calls, sources and run logs as one-line rows that expand, link out or open a dialog, with running, failed and pending states - [Preview](/components/trace).
- 22 examples per base, from a live agent run with Stop and parallel subagents to a Terraform plan behind an approval, a CI re-run, nested request spans, a query plan tree and an access check that explains its decision - [Preview](/components/trace).
- Command output, logs and diffs inside an expanded row render with Code Block, so failing and changed lines keep their color - [Docs](/docs/components/base/code-block).

**New Free Components:**

- 23 new free examples across Trace and File Type, taking the free catalog from 1,241 to 1,264 - [Preview](/components).
- File Type knows 72 more formats, 171 in all: config and infrastructure files such as env, TOML, Dockerfile and Terraform, Vue, Svelte, GraphQL, Kotlin, Swift, Dart, notebooks, Parquet and model weights - [Docs](/docs/components/base/file-type#types-and-colors).
- `getFileType` reads well-known names, where they used to resolve to a blank page: `.env.local` is env, `Dockerfile.dev` a Dockerfile, `.gitignore` git, `go.mod` Go and `LICENSE` text - [Docs](/docs/components/base/file-type#getfiletype).
- New Dotfiles & Build Names example: 12 repository files, `.env.local` and Dockerfile included, each icon read from the name - [Preview](/components/file-type).

**Fixes & Improvements:**

- Data Grid column resizing works in apps that run React Compiler: the width commits and the resize indicator shows while dragging - [Docs](/docs/components/base/data-grid#react-compiler).
- Under React Compiler, the Data Grid also shows edited data, a later `onRowCreate` and changed `getRowStatus` answers, and keeps tree toggles and resize lines live - [Docs](/docs/components/base/data-grid#react-compiler).
- Every Data Grid component file ships with a `"use no memo"` directive, so keep it when you edit an installed file - [Docs](/docs/components/base/data-grid#react-compiler).
- Data Grid rows call the current `onRowClick` and `onRowCreate`, never the one they rendered with - [Docs](/docs/components/base/data-grid).
- A Data Grid whose feature bundle leaves out `columnResizingFeature` renders instead of throwing - [Docs](/docs/components/base/data-grid#tanstack-table-v9).
- Under React Compiler, the Event Calendar's today highlight in the month, week, day and resource views, its Today button and the button's date tooltip move to the new day at midnight, and the agenda shows events as they are added, edited or removed - [Docs](/docs/components/base/event-calendar).
- The Gantt Today button, its date tooltip and `useGanttNavigation().isToday` re-read the clock on every chart change, so under React Compiler they no longer keep the day the chart opened on - [Docs](/docs/components/base/gantt#hooks).
- Under React Compiler, the Date Selector's Today button and year list follow the current date, not the one they mounted on - [Docs](/docs/components/base/date-selector).
- The Cascader runs `resolveValue` with the popup closed and again after a `loadKey` change, so the trigger shows a saved selection's full path without being opened first - [Docs](/docs/components/base/cascader).
- A failed Cascader `resolveValue` is asked again on the next open or `loadKey` change, not on every parent render, where inline `items` and an `onLoadError` that set state re-requested it in a loop - [Docs](/docs/components/base/cascader).
- A Cascader selection resolved by `resolveValue` keeps its full path in the trigger and the columns trail when its level's first page leaves it out, and is listed after that level's rows while the level has pages left - [Docs](/docs/components/base/cascader).
- Opening a Cascader level that a `resolveValue` chain passes through shows its loading state while it fetches, not the resolved node as the level's only row - [Docs](/docs/components/base/cascader).
- A Cascader level that a `path` or `expanded` deep link opens before the level above it loads, or that a `loadKey` change reloads, is fetched by its own value, where `getChildren` used to get `null` and fill it with the root's rows - [Docs](/docs/components/base/cascader).
- A Cascader in `mode="tree"` announces its top level on open, not the drill level holding the selection, and says "Loading..." rather than "Loading more..." while its first page loads - [Docs](/docs/components/base/cascader).
- Pressing a Cascader Retry, in the empty state or in a column, hands focus to the search field (the popup or an inline panel without one), where it used to drop to the page - [Docs](/docs/components/base/cascader).
- The Cascader's Retry after a failed `onSearch` asks the search again, where it retried the level behind the query and nothing happened - [Docs](/docs/components/base/cascader).
- Phone Input's country list scrolls with the mouse down to its last country, and a search with no country match shows "No country found." without a leftover scrollbar, where a search matching only "International" used to leave the list blank - [Docs](/docs/components/base/phone-input).
- An Autocomplete list that filters down to no matches no longer leaves its old scrollbar thumb hanging below the popup - [Preview](/components/autocomplete).
- Base UI previews of 9 examples render the Base UI parts they install, not Radix ones - [Preview](/components).
- Collapsible examples animate open and closed in both bases, and the folder rows of c-collapsible-9 and c-collapsible-10 open from the keyboard - [Preview](/components/collapsible).
- The c-toggle-6 example fills its icon when pressed in the Base UI base too - [Preview](/components/toggle).

Three new in-house primitives, Color Picker, Emoji Picker and File Type, 29 new Stepper examples and grouped Data Grid headers. This entry covers every free change since v2.7.0.

**New: Shadcn Color Picker.**

- New Color Picker primitive: a saturation area, hue, opacity and channel sliders, a hue wheel, preset swatches, an eye dropper and an input that reads any CSS color, in a popover or inline - [Docs](/docs/components/base/color-picker).
- HEX, RGB, HSL, HSB and OKLCH values and fields, OKLCH colors outside sRGB kept exactly, a commit event once a drag ends, and native form fields - [Docs](/docs/components/base/color-picker#value).
- Copy in the format on screen or with Cmd/Ctrl+C, contrast helpers that pick readable text for any color, and 15 examples per base - [Preview](/components/color-picker).

**New: Shadcn Emoji Picker.**

- Hides emoji the device cannot draw, takes single, multiple or form field values, and ships 8 examples per base - [Preview](/components/emoji-picker).

**New: Shadcn File Type.**

- New File Type primitive: a file icon for 99 extensions with outline, solid, light and mono variants, and 6 sizes from 18px to 56px or any size from a Tailwind `size-*` class - [Docs](/docs/components/base/file-type).

- A custom icon on the page with `icon`, and a label badge restyled through `labelClassName` - [Docs](/docs/components/base/file-type#customization).
- `getFileType` picks the type from a file name, path, URL or MIME type, and `getFileTypeCategory` groups files by family for lists and filters - [Docs](/docs/components/base/file-type).

**Data Grid grouped headers:**

- Grouped column headers merge into real `rowSpan` cells, with a rule under each group's own columns and column lines unbroken through every header row - [Docs](/docs/components/base/data-grid#grouped-headers).
- New `meta.headerColSpan` spans one header cell over adjacent columns, as wide as their sum, with one resize handle on its end edge - [Docs](/docs/components/base/data-grid#grouped-headers).
- Header cells carry `data-header-depth`, `data-header-id`, `data-group`, `data-merged` and `data-span` for styling each level - [Docs](/docs/components/base/data-grid#dom-attributes).

**Breaking changes:**

- The Data Grid column window's spacer cells carry `data-col-spacer="start"` or `"end"` instead of `data-slot="data-grid-table-virtual-col-spacer"`, so retarget any CSS that styled them - [Docs](/docs/components/base/data-grid).
- Multi-level Data Grid headers render one `rowSpan` cell where empty placeholder cells used to stack above a column, so retarget CSS that styled those cells - [Docs](/docs/components/base/data-grid#grouped-headers).
- In a multi-level Data Grid header, bottom-row and merged cells hold their content in a `data-slot="data-grid-table-head-cell-band"` wrapper, so retarget selectors on a header cell's direct children - [Docs](/docs/components/base/data-grid#dom-attributes).

**New Free Components:**

- 66 new free examples across Color Picker, Emoji Picker, File Type and Stepper, taking the free catalog from 1,175 to 1,241 - [Preview](/components).
- 29 new Stepper examples, taking Stepper to 44 examples per base - [Preview](/components/stepper).
- 13 Stepper route trackers and stage bars: delivery stops, truck and sea freight routes, shipment checkpoints, and chevron and breadcrumb steps - [Preview](/components/stepper).
- 16 Stepper layouts with step cards, side rails, status lists, color bars and phase tracks, plus nested sub-steps for checks and tasks - [Preview](/components/stepper).

**Fixes & Improvements:**

- Scrolling sideways through a column-virtualized Data Grid holds 120 fps instead of 29, because a column entering view no longer restyles every cell - [Preview](/components/data-grid).
- New `data-dragging` attribute on the Data Grid row being dragged, the hook for styling the slot it leaves - [Docs](/docs/components/base/data-grid#dom-attributes).
- With a sticky header and footer, the Data Grid's vertical scrollbar stops above the footer instead of covering the totals - [Docs](/docs/components/base/data-grid).
- Pin and unpin work in the column virtualization example, and its column jump stays on the named metric after a pin changes - [Preview](/components/data-grid).
- Unpinning a Data Grid column from its header button keeps keyboard focus on that column's menu - [Docs](/docs/components/base/data-grid).
- The Data Grid's column resize line sits on the column edge instead of inside the header cell, in left-to-right and right-to-left layouts - [Preview](/components/data-grid).
- Icon Tile installs with one corner radius per style instead of two competing ones, so a class-sorting formatter can no longer change it - [Docs](/docs/components/base/icon-tile).

## v2.7.0 - 3 October, 2026.

Two new in-house primitives, Signature Pad and Time Picker, with 25 examples per base, plus Cascader global search and a long round of Data Grid fixes. This entry covers every free change since v2.6.0.

**New: Shadcn Signature Pad.**

- New Signature Pad primitive: a `SignaturePadArea` drawing surface under a `SignaturePad` root, with optional `SignaturePadGuide`, `SignaturePadPlaceholder` and corner-pinned `SignaturePadControls`, and undo and redo from the `SignaturePadUndo` and `SignaturePadRedo` buttons or Ctrl+Z, Ctrl+Shift+Z and Ctrl+Y on the area - [Docs](/docs/components/base/signature-pad#signaturepad).
- Ink is SVG and follows the area's text color unless you set `color`, so it stays sharp and tracks the theme; its width comes from pen pressure or drawing speed through `sizing`, between `minWidth` and `maxWidth`, and `pointerTypes={["pen"]}` ignores a resting palm - [Docs](/docs/components/base/signature-pad#signaturepad).
- `serialize` returns the signature as PNG, JPEG, SVG or JSON, with `toSVG`, `toDataURL` and `toBlob` for the markup, a data URL or an upload-ready `Blob`; every export crops to the ink or takes a fixed frame through `padding`, `crop`, `scale`, `background` and `color`, and `SignaturePadPreview` redraws saved strokes as inline SVG with no pad around it - [Docs](/docs/components/base/signature-pad#signaturepadexportoptions).
- `apiRef` on the root and `useSignaturePad` inside it hand `clear`, `undo`, `redo`, `focus` and the four export methods to your own code, and the export helpers also run on a saved stroke array with no pad mounted - [Docs](/docs/components/base/signature-pad#signaturepad).
- A `name` on the root submits the signature with a native form in the chosen `format`, `required` fails while the pad is empty and a form reset restores `defaultValue`; 12 examples per base, from a validated form field and a four-format export to stylus palm rejection, per-clause initials and proof of delivery - [Preview](/components/signature-pad).

**New: Shadcn Time Picker.**

- New Time Picker primitive: hour, minute, second and AM/PM listbox columns in a popover behind `TimePickerTrigger`, or in place with `TimePickerPanel`; `hourCycle` picks a 12 or 24 hour clock, `granularity` the finest column, and the value is an `HH:mm` or `HH:mm:ss` string in 24-hour time whatever is shown - [Docs](/docs/components/base/time-picker#timepicker).
- `hourStep`, `minuteStep` and `secondStep` set which times are offered, `min` and `max` bound them inclusively and run overnight when `min` is after `max`, `isTimeDisabled` marks single times unavailable, and `requireConfirm` keeps a pick a draft until OK - [Docs](/docs/components/base/time-picker#timepicker).
- `TimePickerInput` is a typable field that reads `930`, `14:30`, `14h30` and `2:30 pm`, plus full-width, Arabic-Indic and Persian digits, snaps what you type to the steps and bounds, and steps to the next free time with the arrow keys - [Docs](/docs/components/base/time-picker#timepickerinput).
- On a column the arrow keys move to the next available row without wrapping, Home and End jump to the ends, Page Up and Page Down move 5, Left and Right change column, and typing digits selects a row, with two within a second read as one number - [Docs](/docs/components/base/time-picker#timepicker).
- `i18n` replaces every label and both formatters over the English defaults, `periodPosition="start"` puts AM/PM before the time as Chinese, Japanese and Korean read it, and a `name` submits the value with a native form; 13 examples per base, including EN, DE, ZH and AR labels with Arabic right to left - [Preview](/components/time-picker).

**New Free Components:**

- `Cascader`: new `searchScope="global"` searches the whole tree from whatever level is on screen, where `"deep"` matched only the current level and below; each hit still renders its ancestor trail, and opening a hit outside the current path replaces the path with that hit's own ancestors - [Docs](/docs/components/base/cascader#cascader).
- `Cascader`: new `isCascaderDisabled(index, node)` helper and a matching `isDisabled` on `useCascaderActions()`, so a hand-written row, trigger or chip list can ask the same disabled question the built-in rows ask instead of reading `node.disabled` and missing a disabled ancestor - [Docs](/docs/components/base/cascader#cascader).
- New Cascader example: a product category field that reopens on the level its value lives in and still searches the whole catalog, including two same-named rows that only their trails tell apart, taking the Cascader to 21 examples per base - [Preview](/components/cascader).
- 26 new free examples across Signature Pad, Time Picker and Cascader, taking the catalog from 1,149 to 1,175 and the in-house primitives from 22 to 24 - [Preview](/components).

**Fixes & Improvements:**

- `Cascader`: `disabled` on a branch now disables its whole subtree - wherever a descendant surfaces, the row renders dimmed and `aria-disabled`, and row presses, the keyboard and hover-to-open all refuse it, where before pressing a leaf hit under a disabled branch selected it - [Docs](/docs/components/base/cascader#cascader).
- `Cascader`: the two deliberate ways out of a disabled subtree still work - what `expanded` holds open in `mode="tree"` can be collapsed, and a disabled value already in the selection stays removable through its chip, `remove` or `clear` - [Docs](/docs/components/base/cascader#cascader).
- `Cascader`: `CascaderItemState.disabled`, the second argument handed to `renderItem` and `renderLabel`, now reports the node's own flag or any ancestor's, so a custom row styles itself the way the built-in row does - [Docs](/docs/components/base/cascader#cascader).
- `Cascader`: opening a search hit whose children still have to be fetched rebuilt the path from the level you were standing on, so a hit more than one level down landed under the wrong ancestors with the levels in between skipped - [Docs](/docs/components/base/cascader#cascader).
- `Kanban`: the drop target follows the pointer instead of the dragged card's rectangle overlap, so dragging through the gap between two columns no longer flips the target back and forth and bounces the live preview between them - [Preview](/components/kanban).
- `DataGrid`: picking an option in an in-cell select, combobox, popover or menu no longer starts or extends a cell selection and no longer fires `onRowClick`, so the pick applies instead of being swallowed by the selection session - [Docs](/docs/components/base/data-grid#datagridcellselection).
- `DataGrid`: clicking a column header that is only resizable no longer sorts by it, so a column with sorting disabled can no longer replace the grid's active sort - [Docs](/docs/components/base/data-grid).
- `DataGrid`: live column resizing (`columnsResizeMode: "onChange"`) moves the table width, the viewport width and the fill strip with the dragged column, so the remaining columns no longer jitter until the release - [Docs](/docs/components/base/data-grid#datagrid).
- `DataGrid`: an armed `meta.autoSize` column reflows during a live resize of a neighbouring column instead of jumping once the drag is released - [Docs](/docs/components/base/data-grid).
- `DataGrid`: a `meta.autoSize` column with no `minSize` of its own now shrinks only back to its starting width; TanStack's built-in 20px default no longer counts as a floor - [Docs](/docs/components/base/data-grid).
- `DataGrid`: pinned cells, their hover, selected and `getRowStatus` tints and the footer band paint `--data-grid-surface`, which falls back to `--background` and follows `--card` inside a shadcn `Card`; set it on an ancestor for any other surface - [Docs](/docs/components/base/data-grid#datagridtable).
- `DataGrid`: those premixed tints are gated on `columnsPinnable`, so pinning used only as a column-order lock no longer paints pinned cells a second hover colour - [Docs](/docs/components/base/data-grid#datagridtable).
- `DataGrid`: loading skeleton cells carry the pinning of the columns they stand in, so a skeleton grid no longer unpins while it loads - [Docs](/docs/components/base/data-grid#datagridtable).
- `DataGrid`: both scrollbars are `--data-grid-scrollbar-size` thick, 10px by default, and the whole track thickness grabs the thumb; set the variable on an ancestor for a larger drag target - [Docs](/docs/components/base/data-grid#datagridscrollarea).
- `DataGrid`: on an RTL page the scrollbar thumb follows the scroll again, because `DataGridScrollArea` reads its direction off the rendered layout, so neither library's `DirectionProvider` is needed - [Docs](/docs/components/base/data-grid#datagridscrollarea).
- `DataGrid`: pinned-column separators stay on their inline seam in an RTL layout, and keyboard column reordering works there too, where an arrow key near the start edge used to move nothing - [Docs](/docs/components/base/data-grid#datagridtable).
- `DataGrid`: `DataGridPagination` and the column filter use `gap-x-*` instead of `space-x-*`, so an RTL install no longer has the shadcn CLI flip their spacing onto the wrong side - [Docs](/docs/components/base/data-grid#datagridpagination).
- `DataGrid`: `DataGridTableDnd` and `DataGridTableDndRows` take an `accessibility` prop forwarded to dnd-kit's `DndContext`, so its screen-reader instructions and drag announcements can be localized alongside the grid's own `i18n` - [Docs](/docs/components/base/data-grid#datagridtablednd).
- `DataGrid`: column drag and drop leaves pinned columns alone - a pinned column renders without a grip and is neither a drag source nor a drop target, and keeps its sticky position while the rest of the row is dragged - [Docs](/docs/components/base/data-grid#datagridtablednd).
- `DataGrid`: `Move Left` and `Move Right` in the column header menu step over the columns the grid actually renders in that column's pin group, so they no longer swap with a hidden column and do nothing - [Preview](/components/data-grid).
- `DataGrid`: the column visibility checkboxes only title-case a column whose label is its raw `id`, so a column with an authored header label keeps its own casing, and the empty message is centred on the visible part of a grid wider than its scroll area - [Preview](/components/data-grid).
- The Data Grid docs import from `@/components/reui/data-grid/data-grid` and its siblings instead of the bare directory, which the installer never creates, and they now note that an RTL grid also needs `columnResizeDirection: "rtl"` on `useTable` - [Docs](/docs/components/base/data-grid).
- The Radix docs for Badge, Date Selector, Sortable, Timeline and Tree told you to install `@reui/r-badge` and import from `@/components/reui/r-badge`, an `r-` prefixed item the registry has never published; both bases ship the same `@reui/<name>` - [Docs](/docs/components/radix/badge).
- The integration notes on 12 component pages carried 15 links to pages that do not exist, such as `/components/form` and `/components/data-table`; each is now plain text or points at the real page - [Preview](/components).

## v2.5.5 - 16 September, 2026.

ReUI follows shadcn onto the `cn` package, and the Event Calendar and Data Grid each get back an interaction that was unreachable before.

**Breaking changes:**

- ReUI items that merge classes now import `cn` from the [`cn` package](https://www.npmjs.com/package/cn) instead of your `@/lib/utils`, following shadcn upstream - [Docs](/docs/registry#class-merging).
- Any item that imports it lists `cn` in its `dependencies`, so `shadcn add` installs the package on the first such install - [Docs](/docs/registry#class-merging).
- Items already installed keep working and your `@/lib/utils` is untouched - [Docs](/docs/registry#class-merging).
- To drop `clsx` and `tailwind-merge` from your own project, run `pnpm dlx shadcn@latest migrate cn` - [Changelog](https://ui.shadcn.com/docs/changelog/2026-09-cn).
- If you had customized `cn` in `@/lib/utils`, rebuild it with `createCn` from `cn/config`; newly installed items no longer route through that file - [Docs](/docs/registry#class-merging).

**Fixes & Improvements:**

- `EventCalendar`: timed views reserve a clickable strip at the end of each day column, so a press beside a full-width block creates a new event instead of doing nothing - [Preview](/components/event-calendar).
- `EventCalendar`: the strip's width is the `--ec-event-gutter` custom property, default `0.75rem`; set `classNames.dayColumn: "[--ec-event-gutter:0px]"` to restore edge-to-edge blocks - [Docs](/docs/components/base/event-calendar).
- `DataGridPagination`: moved from fixed page blocks to an adaptive window carrying the first and last page, so the last page is always one click away instead of several ellipsis steps - [Docs](/docs/components/base/data-grid#datagridpagination).
- `DataGridPagination`: the existing `moreLimit` prop now counts the buttons in the truncated middle and is rounded down to an odd count with a floor of 3; page buttons carry a per-style min-width so the row keeps a steady width as you page - [Docs](/docs/components/base/data-grid#datagridpagination).
- `Cascader`: virtual rows froze at their first window in apps built with React Compiler, which cached the row list against a virtualizer identity that never changes - [Preview](/components/cascader).
- `Filters`: `defaultOperator` now documents what it does - the operator a rule falls back to when its field changes, not a preselection on create - [Docs](/docs/components/base/filters).
- `Frame`: the radius ladder was structurally broken and is now resolved per style - [Preview](/components/frame).
- `NumberField`: size ladders restored across all 8 styles - [Preview](/components/number-field).
- `DataGrid`: the column resize handle used a non-Tailwind class to suppress text selection during a drag - [Preview](/components/data-grid).
- Two Button examples imported a hook from a path no installer creates, so they failed to build once installed - [Preview](/components/button).
- Four example files carried broken class strings and a dead variant - [Preview](/components).
